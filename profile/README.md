## The cloud for AI agents

**Agent swarms run on Mapier.** Real computers and phones on every operating system,
storage beside them, and real iMessage and phone-number lines. One cloud, built for
AI agents, with storage and compute at its core.

| | |
| --- | --- |
| [**Mapier Pod**](https://mapier.ai/pod) | Computers and phones for agents: macOS, Windows, Linux, iOS and Android sandboxes from one API. |
| [**Pod CI/QA**](https://mapier.ai/pod/ci) | CI and visual QA, built for coding agents. Change one line and your workflows run on Pod. |
| [**Pod Console**](https://mapier.ai/pod/console) | Every agent's work, shared. One list for every agent session, and one click moves a long run to a sandbox. |
| [**Pod Agent IAM**](https://mapier.ai/pod/iam) | Permissions enforced by the system, not by the prompt. |
| [**Mapier Convo**](https://mapier.ai/convo) | Real iMessage and phone-number lines for your agent, with WhatsApp, Discord and Slack on the same API. |

**Also from Mapier:** [Mapier Data](https://mapier.ai/data), RL environments and evals built on licensed company archives, and [Mapier Persona](https://mapier.ai/persona), paid research studies over iMessage.
